# The block diagrams of the tutorial

| File | What it shows |
|---|---|
| `pipeline.drawio`, `pipeline.png` | the path from a Hamiltonian to counts |
| `circuit.drawio`, `circuit.png` | the job MAIN, one bond, and the recipe for any Pauli term |

The `.drawio` file is the source. Export it with `drawio -x -f png -s 1.5 -b 10 -o NAME.png NAME.drawio`.
